Консольное приложение для учёта личных финансов: доходы и расходы, категории,
бюджеты, отчёты и переводы между пользователями. Поддерживает несколько
учётных записей и обмен данными в JSON и CSV. Интерфейс на русском языке.

## Запуск

Требуется JDK 21 или новее и консоль с поддержкой UTF-8.
Команды выполняются из корня проекта:

```sh
./mvnw package
java -jar target/FinanceTracker-1.0.jar
```

Альтернативный запуск:

```sh
./mvnw -q compile exec:java
```

На Windows вместо `./mvnw` используется `mvnw.cmd`.

## Использование

Команда `register` создаёт учётную запись, `login` открывает существующую.
Логин и пароль запрашиваются отдельно. После входа доступны операции с кошельком:

```text
add-category Зарплата
add-category Еда
set-budget Еда 4000
add-income Зарплата 60000
add-expense Еда 300 "обед"
report
history
```

Полный список команд, форматы и примеры доступны через `help`.

| Команды | Назначение |
|---|---|
| `register`, `login`, `logout` | Регистрация, вход и выход из учётной записи |
| `categories`, `add-category`, `rename-category`, `remove-category` | Управление категориями |
| `set-budget`, `remove-budget` | Управление бюджетами категорий |
| `add-income`, `add-expense` | Добавление доходов и расходов |
| `transfer` | Перевод другому пользователю |
| `report`, `history` | Финансовый отчёт и история операций |
| `export`, `import` | Обмен данными в JSON и CSV |
| `exit` | Завершение работы |

Названия и описания с пробелами заключаются в двойные кавычки.
Для операций и переводов доступна опция `--date ГГГГ-ММ-ДД`; будущие даты запрещены.
Отчёт и история поддерживают фильтры `--categories`, `--from`, `--to`
и сохранение в файл через `--out`.

Бюджеты учитывают всю историю, а в отчёте с периодом — выбранные расходы.
Оповещения показывают достижение 80% бюджета, перерасход и состояние баланса.
Обычные расходы допускают отрицательный баланс; переводы требуют достаточных средств.
Категория с операциями не может быть удалена.

## Данные и настройки

Настройки находятся в `config/app.properties`:

```properties
storage.file=data/finance.json
logs.directory=logs
password.iterations=600000
```

Данные сохраняются автоматически в JSON. Перевод изменяет оба кошелька одновременно;
при ошибке сохранения изменения не применяются. Пароли хранятся в виде хешей.
При вводе в консоли пароль может отображаться на экране.
Журналы работы записываются в `logs/YYYY-MM-DD.log`.

Экспорт JSON содержит категории, бюджеты и операции кошелька; CSV — только операции.
Импорт добавляет операции и недостающие категории, а бюджеты из JSON заменяют
соответствующие существующие лимиты. Повторный импорт создаёт дубликаты операций.
Импортированные записи переводов не отправляют деньги другим пользователям.
Существующие файлы при экспорте и сохранении отчётов не перезаписываются.

## Архитектура

| Пакет | Назначение |
|---|---|
| `model` | Пользователи, кошельки, операции, категории и бюджеты |
| `service` | Бизнес-правила, авторизация, расчёты и переводы |
| `repository` | Интерфейсы хранилищ и реализации для JSON |
| `controller` | Команды CLI, сессия и форматирование вывода |
| `config` | Загрузка и проверка настроек |
| `libs` | Транзакционное JSON-хранилище, логи, CSV и хеширование паролей |

CLI обращается к сервисам, доступ к данным организован через интерфейсы
репозиториев. Модель не зависит от консоли и файлового хранения.
`Application` связывает компоненты; `Main` служит точкой входа и настраивает логи.

## Проверки

Модульные и интеграционные тесты выполняются через JUnit Jupiter:

```sh
./mvnw test
```

Полная проверка включает тесты, минимальное покрытие 50% строк,
Checkstyle и Spotless:

```sh
./mvnw verify
```

Отчёт JaCoCo: `target/site/jacoco/index.html`.
Результаты тестов: `target/surefire-reports/`.
